Original pre-review data used for the SLM labeling pilot

candidates.jsonl: exact copy of the 111 unreviewed candidate decisions used for labeling. Includes conversation history, triggering message, original observed response, context, and source IDs. No review labels or edited target replies have been added.

candidates-readable.json: the same 111 records formatted for easier reading.

manifest.jsonl: original extraction metadata and checksum.

These candidates were extracted from 262 source rows across a pilot capped at 25 prospects. This is the pre-review, pseudonymized labeling input, not an untouched database dump or the final 50 accepted examples. The extraction reports history truncation for all 111 candidates, so histories may be incomplete. Pseudonymization does not guarantee removal of every identifying detail.
